## 1. 数据来源

### 1.1 字表与字词属性

| 项 | 说明 |
| --- | --- |
| 内容 | 一年级上册 / 下册、二年级上册 / 下册的识字表、写字表、课文分组、拼音、部首、组词 |
| 依据 | 统编版（部编版）小学语文教材 |
| 整理来源 | [fsiceangel/zishi](https://github.com/fsiceangel/zishi)（开源整理项目，其 README 说明数据对应统编版教材） |
| 落地文件 | `content/source/{volumes,chars,words,radicals}.json` → 构建为 `miniprogram/data/*.js` |
| 校验 | `scripts/build-data.mjs` 强制校验 300/400/450/450 = 1600 字，笔画数与中线数一致，构建失败即中止 |

**请注意**：仓库中**没有**该数据的明确开源许可证文件。因此本项目对这部分数据的态度是：

- 仅将其作为**教材事实性内容**（生字表、拼音、部首属于客观事实，不构成独创性表达）；
- **不复制**教材的课文原文、插图、练习设计；
- 若你打算商用，请自行与数据整理方确认，或直接依据纸质教材重新校对字表。

| §2(a) 修改声明 | 修改过的文件须显著说明"何时、如何修改" | `scripts/build-data.mjs` 顶部注释说明：将 SVG 轮廓转换为量化二进制；输出文件头注释标明"由脚本生成" |

**商用注意**：

- 可以随小程序免费分发；

- 若修改数据（如重新量化、增删字），必须继续以 Arphic Public License 提供修改后的数据，并在文件里写明改动。

## 3. 小程序上架合规

### 3.1 类目与服务内容

| 项 | 建议 |
| --- | --- |
| 类目 | 教育 → 教育信息服务（**不需要**办学许可证，因为不提供学科培训、不收费、不做直播） |
| 内容 | 工具型：字表浏览 + 笔顺演示 + 本地练习记录 |
| 不做 | 不做在线课程、不做付费、不做老师入驻、不做 UGC 社区 |

> 若后续加入"老师布置作业 / 班级"，会触及教育类目的额外资质要求，需要重新评估。

### 3.2 未成年人保护

- **不收集任何个人信息**：无登录、无手机号、无头像昵称、无定位、无设备标识上报。
- **无社交**：没有好友、评论、排行榜、分享得奖励。
- **无付费**：没有内购、没有广告。
- **单次任务有边界**：每日新学默认 5 字，做完提示"明天见"，不设计无限关卡。
- 关于页写明"每次 10 分钟"的家长建议。

对应《未成年人保护法》网络保护专章与《未成年人网络保护条例》的基本要求：无沉迷诱导、无消费诱导、无隐私收集。

### 3.3 隐私协议

小程序**不涉及**用户信息收集，因此在微信后台的《用户隐私保护指引》中应勾选"不收集任何信息"，并在"关于"页给出说明（已实现）：

> 所有学习记录只保存在这台手机的本地存储里，不上传服务器，也不收集任何个人信息。清除小程序缓存会同时清除记录。

如果未来接入 `wx.getUserProfile`、云开发或统计 SDK，**必须**同步更新隐私指引，否则审核会被拒。

### 3.4 审核易踩的坑

| 坑 | 规避 |
| --- | --- |
| 首页出现"课本""教材""人教版"被判定为教培 | 文案用"统编版语文课本顺序"，不出现培训机构、提分、押题等词 |
| 空白页 / 无内容 | 11 个页面均有内容，`npm run lint` 检查每页四件套齐全 |
| 功能不完整（点了没反应） | 所有可点元素均绑定事件，预览脚本对导航与答题做断言 |
| 分包加载失败 | 主包不引用分包文件（lint 强制检查），路由集中管理 |
| 版权投诉 | 关于页明确标注数据来源与许可证，包内附许可证全文 |

1. 与字表整理方确认授权，或按纸质教材重新校对（生字表本身是事实性内容，风险较低，但组词例句可能有独创性）。

3. 若接入任何统计、登录、支付，重写隐私指引与未成年人保护方案。
4. 小程序名称、图标不要与教材出版方（人教社等）产生关联暗示。
