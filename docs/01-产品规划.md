# 小小识字家 · 产品规划

> 面向小学一、二年级的汉字学习微信小程序
> 版本：v1.0 ｜ 定位：课后 3 分钟的字词练习工具（家长陪伴 / 孩子自己玩）

---

## 1. 为什么做

### 1.1 用户是谁

| 角色 | 画像 | 真实诉求 |
| --- | --- | --- |
| 主要用户：孩子 | 6–8 岁，刚学完拼音或正在学，识字量 0–1600 | 想知道"这个字怎么写"、"我写对了吗"；注意力只能维持 3–5 分钟 |
| 决策者：家长 | 一二年级学生家长 | 想让孩子把课本生字写对、记住；不想下载 App、不想注册、不想付费 |
| 次要用户：老师 | 低年级语文老师 | 布置"回去把这一课的字写一写"，需要一个能自己纠错的工具 |

### 1.2 现有产品的问题

- **识字 App 太重**：开屏广告、付费墙、虚拟货币、社交排行 —— 家长不放心，孩子易分心。
- **只有"认"没有"写"**：多数产品是翻卡片认字，孩子认得但写不对笔顺。
- **笔顺动画不可交互**：只能看，不能上手写；写完也没人告诉自己"哪里错了"。
- **和课本对不上**：字表顺序和统编版教材不一致，家长没法"跟着今天讲的课练"。

### 1.3 产品主张

> **跟着课本，一笔一笔写对。**

三句话定义边界：

1. **只做课本里的字** —— 统编版一、二年级 1600 个生字，一课不多一课不少。
2. **只做"写"这件事** —— 笔顺动画 + 描红评分，把"写完有人看"做扎实。
3. **只做 3 分钟** —— 每个学习循环 5 个字 / 5 道题，做完就走，不设计上瘾机制。

## 2. 学习设计

### 2.1 一个学习闭环

```
学（看动画 + 认读）
   ↓
写（描红评分，逐笔纠错）
   ↓
测（5 种题型随机抽）
   ↓
复习（间隔重复，错了自动进错题本）
   ↓
回到"学"（明天先复习到期的字）
```

### 2.2 设计原则

| 原则 | 落地做法 |
| --- | --- |
| 一次只做一件事 | 每屏只有一个主按钮；描红页不出现"下一课"以外的入口 |
| 即时反馈 | 每写完一笔立刻判定（通过 / 提示原因），不等整字写完 |
| 正向措辞 | 失败提示是"起笔的位置不对，从红色小点开始写"，不是"错误" |
| 降低认知负荷 | 笔画引导线 + 起笔红点 + 序号，孩子不需要记"第几笔" |
| 家长可见的进步 | "我的"页展示累计识字、掌握、连续天数、7 日柱状图 |
| 不制造焦虑 | 没有排行榜、没有"你的好友已学 100 字"、没有倒计时 |

### 2.3 内容覆盖

| 册次 | 生字 | 会写 | 单元 | 课 |
| --- | --- | --- | --- | --- |
| 一年级上册 | 300 | 100 | 8 | 41 |
| 一年级下册 | 400 | 200 | 8 | 36 |
| 二年级上册 | 450 | 250 | 8 | 36 |
| 二年级下册 | 450 | 250 | 8 | 37 |
| **合计** | **1600** | **800** | **32** | **150** |

每个字包含：拼音（含多音字按课次区分）、部首、笔画数、结构、组词（带拼音）、笔顺（分笔矢量）。

## 4. 功能分期

### MVP（v1.0，本次已实现）

| 模块 | 功能 | 状态 |
| --- | --- | --- |
| 内容 | 4 册 1600 字、150 课、拼音/部首/组词/笔顺 | ✅ |
| 学 | 单元 → 课文 → 生字 → 字详情 | ✅ |
| 看 | 笔顺逐笔动画、重播、单笔回放、序号 | ✅ |
| 写 | 描红评分、逐笔纠错、提示/撤销/重写、星级 | ✅ |
| 测 | 5 种题型、随机 5 题、按册练习 | ✅ |
| 复 | Leitner 间隔重复、错题本 | ✅ |
| 看进度 | 今日任务、连续天数、徽章、7 日图 | ✅ |
| 设置 | 每日字数、动画速度 | ✅ |

### V1.1（可选增强）

- 语音朗读（拼音 / 组词），需要 `wx.createInnerAudioContext` + 音频资源
- 听写模式：播读音，孩子写字
- 家长报告：一周学习摘要（可分享到家庭群）
- 生字表导出为图片，方便打印

### V2（需要后端）

- 微信云开发同步学习进度（多设备）
- 老师建班级、布置"第 3 课生字"
- 语音识别打分（读得准不准）

> 明确不做：社交、排行榜、付费点、广告、虚拟宠物。

## 5. 关键指标

| 指标 | 定义 | 目标 |
| --- | --- | --- |
| 首次学习完成率 | 打开 → 完成第一个字的描红 | ≥ 60% |
| 单次时长 | 一次会话 | 3–6 分钟 |
| 次日留存 | 第二天再打开 | ≥ 35% |
| 描红通过率 | 单笔首次通过比例 | 55%–75%（太低挫败，太高无挑战） |
| 7 日掌握量 | 进入 SRS 第 5 盒的字数 | ≥ 20 字 |

## 6. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 手指书写体验差（屏幕小、笔画细） | 通过率低、挫败 | 容差按画布尺寸自适应（7.5%），粗笔画引导，允许"过了就行" |
| 孩子不认字也不认拼音 | 题型看不懂 | 题型以"看拼音选字""看字选拼音"为主，选项大、有图形式反馈 |
| 教材版本差异 | 家长发现字表不一致 | 明确标注"统编版（部编版）"，关于页给出出处 |
| 笔顺数据版权 | 合规风险 | 采用 Arphic Public License 的开源笔顺数据，保留声明（见合规文档） |
| 主包 2MB 限制 | 无法上传 | 笔顺数据放分包，主包 464KB |
| 家长担心沉迷 | 差评 | 无广告无内购、单次任务有限、关于页写明"每天 5 字即可" |

## 7. 验收标准（v1.0）

- [x] 4 册书、150 课、1600 字全部可点开，无空白页
- [x] 任意字可播放笔顺动画，笔画数、顺序与教材一致
- [x] 描红可逐笔评分，写对进下一笔，写错给具体原因
- [x] 5 种题型均能出题、判定、给解析
- [x] 学习记录本地持久化，重启小程序后仍在
- [x] 主包 < 2MB，分包可正常预载
- [x] 47 个单元测试 + 静态检查 + 渲染自检 + 浏览器交互断言全绿
